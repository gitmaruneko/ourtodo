# 群組待辦清單

同一個 Cloudflare 網站可建立多個群組，不需要為每個 LINE 聊天室分別部署。

## 使用方式

1. 登入後，在清單上方選擇群組，或點選「群組管理」。
2. 輸入名稱建立群組。建立者是群組管理員，新群組的任務清單為空白。
3. 管理員可複製群組專屬邀請連結，交給要加入的成員。
4. 收到邀請的人從連結登入。新帳號會自動核准並加入該群組，不需等待管理員；既有帳號也會直接加入。已停用的帳號不會被邀請連結重新開通。也可在群組管理中貼上邀請碼並按「加入」。
5. 同一帳號可加入多個群組，在清單上方切換。新增、編輯、統計、搜尋與「我的任務」都只作用於目前群組。

群組管理員可以編輯共用群組名稱、查看成員、移除成員、更新邀請連結。其他成員可以查看及編輯群組任務。更新邀請連結後，舊連結失效，既有成員仍留在群組內。若要避免被移除的成員透過舊連結再次加入，請同時更新邀請連結。

群組管理中的「清單配色」提供森林綠、海洋藍、薰衣紫、暖陽橘、玫瑰粉、石墨灰六款配色。管理員點選後立即儲存在群組設定中；其他成員會使用相同配色。切換群組時會套用該群組的背景、標題、主要按鈕與表格配色。已開啟的頁面每 30 秒同步群組設定，重新整理也可立即取得最新配色。既有群組預設為森林綠。

成員姓名旁會顯示所有已加入的群組名稱，不再顯示「已核准」。有效邀請會以同一個資料庫批次完成帳號核准與群組加入，失敗時整批回復。無效或已更新的邀請連結不會核准帳號；一般首頁登入也不會自動核准或任意加入群組。舊版等待核准的人再次開啟有效邀請連結即可完成加入。舊版已記錄的群組申請仍相容於管理員手動核准。

群組由本網站管理，不會自動取得或同步 LINE 聊天室的成員。只在 LINE 聊天室轉貼一般首頁網址，不會自動加入對應群組。

## 舊資料與部署

部署流程會先套用 D1 migrations，再更新網站程式。`0003_groups.sql` 會將既有任務移至「原有共用清單」，並將升級當時已核准的成員加入該群組。原網站管理員成為這個群組的管理員。升級後新核准的帳號，仍需透過邀請加入群組。

先前的個人標題設定保留在資料庫中供舊版本相容使用；新版主標題使用群組共用名稱，由群組管理員編輯。切換群組的選擇會依帳號記在目前瀏覽器中，也可透過 `?group=...` 連結開啟自己已加入的群組。

任務、負責人選項與群組名單皆在伺服器驗證群組成員資格；照片也必須由目前使用者所屬群組的任務引用才能存取。網站管理員不會自動取得其他人新建群組的任務存取權。
